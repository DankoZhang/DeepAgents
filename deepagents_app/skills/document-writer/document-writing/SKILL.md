# 文档撰写 Skill

## 何时使用

- 用户要求「写一份…」「整理成文档」「生成 README」
- 需要统一标题层级、目录与落盘命名

## 推荐结构模板

```markdown
# 标题

## 背景
（为什么做）

## 目标
（做成什么样，可验收）

## 方案 / 正文
（分点论述）

## 风险与假设
（可选）

## 下一步
（可选）
```

## 落盘约定

- 目录：`documents/`
- 文件名：小写英文 + 连字符，例如 `api-design.md`
- 编码：UTF-8

## 质量检查清单

1. 是否有清晰的一级标题？
2. 是否避免大段无结构散文？
3. 是否写明假设与未决问题？
