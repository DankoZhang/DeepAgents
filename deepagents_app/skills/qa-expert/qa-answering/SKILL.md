# 智能问答 Skill

## 标准流程

1. `search_knowledge(query)` 检索
2. 命中 → 引用 `kb-xxx` 组织答案
3. 未命中 → 通用知识作答并标注「非知识库来源」
4. 高价值问答 → `save_qa_note` 沉淀

## 回答模板

```markdown
**结论**：……

**说明**：
- …

**来源**：知识库 kb-00x / 非知识库来源
```

## 注意

- 不编造知识库中不存在的条目 id
- 区分事实与推断
